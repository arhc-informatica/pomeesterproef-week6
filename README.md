# PO Meesterproef — Week 6 (Oplevering & Mondeling Gesprek)

Dit is de **week 6**-versie. Er is **geen nieuwe code** in deze week: je levert je werk op en verdedigt je code.

Je mag een eigen onderwerp kiezen.

## Wat zit erin?

Deze week bevat **geen nieuwe code**. Je gebruikt je bestaande project (week 4/5) voor de oplevering.

## Live demo voorbereiden

Bereid een korte live-demonstratie voor van je werkende site. Hints:

- **Test je site van tevoren** op de computer die je bij de demo gebruikt; open alle pagina's.
- **Start de app vroeg** (`python app.py`) en laat hem draaien; controleer http://127.0.0.1:5000.
- **Reset de database** als dat nodig is (`rm data.db` en opnieuw starten) zodat je met schone data begint.
- **Doorloop je demo-stappen** een paar keer: homepage → formulier → opslaan → lijst met data.
- **Houd het kort**: laat de hoofdfuncties zien, niet elke detail.
- **Bereid een fallback voor**: screenshots of een video als de live-site niet werkt.
- **Zorg dat je code op GitHub staat** en dat je weet waar je bestanden staan.

## Code-verdediging voorbereiden

Je legt in heldere en correcte taal uit hoe je code en SQL-queries werken (ca. 10 minuten). Hints:

- **Lees je eigen code door** en leg in eigen woorden uit wat elke route doet.
- **Bereid uitleg voor van je SQL-queries**: `SELECT`, `INSERT`, `WHERE`, `ORDER BY`.
- **Bereid uitleg voor van je HTML/CSS**: structuur, formulier, menu, styling.
- **Oefen hardop**: vertel je uitleg aan een klasgenoot of in de spiegel.
- **Oefen samen**: stel elkaar vragen zoals de docent dat zou doen (bijv. "Wat gebeurt er als de naam leeg is?", "Waarom gebruik je `?` in de query?", "Hoe komt data van het formulier in de database?").
- **Vraag elkaar door**: blijf vragen tot je zeker weet dat je het begrijpt.
- **Maak aantekeningen** van punten waar je vastloopt en zoek ze op.

## Opdrachten (week 6)

- Bereid je live demo voor en oefen hem een paar keer.
- Bereid je code-verdediging voor en oefen met een klasgenoot.
- Doe de live-demonstratie aan de docent.
- Voer het Code-Verdedigingsgesprek (10 minuten).
- Lever je evaluatieverslag in (max. 2 A4's, zie hoofdstuk 4).
- Zorg dat al je definitieve code en bestanden op GitHub staan.

## Hulp

### Demo

- **Checklist voor de demo**: app draait, pagina's open, data aanwezig, fallback (screenshots) klaar.
- **Als iets misgaat**: blijf rustig, leg uit wat er zou moeten gebeuren en toon je code.

### Code-verdediging

- **Gebruik je eigen woorden**; geen jargon zonder uitleg.
- **Wijs in je code** waar de betreffende regel staat.
- **Oefen vragen**: "Wat doet deze route?", "Wat is het verschil tussen GET en POST?", "Waarom `?` in de query?".

### Hulp

- **App starten:** `python app.py` en open http://127.0.0.1:5000.
- **Database resetten:** verwijder `data.db` en start de app opnieuw.
- **GitHub:** commit en push regelmatig (`git add .`, `git commit -m "..."`, `git push`).
